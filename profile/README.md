## What Is FX Draw

FX Draw is Efofex’s Windows diagram tool for mathematics teaching. You open it because a geometry problem on a test you write needs a clean triangle, or a calculus sheet needs a sketched derivative. FX Draw math diagrams is the canvas. FX Draw geometry figure is the constrained drawing. FX Draw graph sketch is the function plot. FX Draw teacher drawing is the habit of building a library of figures that belong to your courses.

It is not AutoCAD, not a CAS that solves the student’s homework, and not MathMagic’s equation-glyph editor. Teachers, tutors, and authors who already produce packets look this up when Word’s drawing tools fight back. Markings for congruence, dashed lines for hidden edges, and statistical plots sit in one palette.

Use it on materials for classes you teach or books you have the right to illustrate. Keep a folder per course. Do not scrape figures from a publisher you do not have a license to copy.
